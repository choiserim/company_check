# 기업 컨설팅 브리핑 생성기

기업신용조사보고서(PDF) 등 **업로드한 파일의 내용을 읽어 19페이지 컨설팅 브리핑 양식에 자동으로 작성**하고,
목차 네비게이션으로 페이지를 오가며 내용을 직접 수정한 뒤,
**파워포인트에서 편집 가능한 `.pptx` 파일로 내려받는** 단일 HTML 웹페이지입니다.

빌드 도구·서버·설치 과정이 없습니다. `index.html` 파일 하나가 전부입니다.

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 파일 업로드 | 드래그&드롭 또는 파일 선택. PDF · XLSX · XLS · CSV · TXT · DOCX · PPTX |
| 자동 작성 | 추출한 값을 19페이지 브리핑 양식의 표·KPI 카드·차트·점검항목 문장에 채워 넣음 |
| 목차 네비게이션 | 좌측 사이드바에서 표지 · 목차 · 01~06 섹션과 하위 페이지로 즉시 이동, 스크롤 위치 자동 하이라이트 |
| 인라인 편집 | 모든 텍스트와 표 셀을 클릭해 바로 수정, 수정 결과가 다운로드에 그대로 반영 |
| PPTX 다운로드 | 16:9 규격, 텍스트박스 · 도형 · 표 · 네이티브 차트로 생성 → 파워포인트에서 자유롭게 편집 가능(이미지 아님) |
| 작업 저장 / 불러오기 | 작성 중인 내용을 JSON으로 저장하고 다시 불러오기 (`Ctrl+S`) |

---

## 사용 방법

### 1) 로컬에서 바로 열기

`index.html`을 다운로드해 더블클릭하면 기본 브라우저에서 실행됩니다.
(외부 라이브러리를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

### 2) GitHub Pages로 배포하기

저장소 **Settings → Pages → Source: GitHub Actions** 를 선택하면
포함된 워크플로(`.github/workflows/deploy-pages.yml`)가 `main` 브랜치를 그대로 배포합니다.

배포 주소: `https://<사용자명>.github.io/<저장소명>/`

> Pages 없이 **Deploy from a branch → main / (root)** 를 선택해도 동일하게 동작합니다.

## 인식하는 항목

기본 파서는 **기업신용조사보고서(KOREA RATING & DATA) 기업종합보고서** 형식에 맞춰져 있습니다.

- **기업개요** — 기업명 · 영문명 · 사업자번호 · 법인번호 · 대표자 · 설립일(업력) · 업종 · 주요제품 · 소재지 · 종업원수 · 자본금 · 기업규모 · 결산월
- **신용정보** — 기업신용등급 · 법인등기정보 · 휴폐업정보 · 주채권기관 · 당좌개설/카드발급 건수 · 신용도판단/공공정보 등 특이사항
- **주주 · 경영진** — 주주명/지분율/관계, 성명/직위/등기여부/비고
- **거래처** — 주요 구매처 · 판매처와 거래비중 (셀 안에서 줄바꿈된 상호도 복원)
- **사업장** — 자가소유 여부 · 실제가동 여부 · 대지/건물 면적 · 입지조건 · 담보제공 여부
- **재무제표(3개년)** — 손익계산서 · 재무상태표 상세(단위 천원 → 백만원 환산), 감가상각비 · 이자비용 · 퇴직급여 · 보험료
- **재무비율 · 업종평균** — 성장성 · 수익성 · 안정성 · 활동성 지표와 동종업계 평균 비교
- **인증 · 산업재산권** — 벤처 · 이노비즈 · 메인비즈 · 연구개발전담부서 · 부설연구소 / 특허 · 실용신안 · 디자인 · 상표권
- **업계순위** — 동종업계 매출 순위

증감률 · EBITDA · 자기자본비율 · 업력 등 파생 지표와 일부 점검항목 문장(예: *"상시근로자 66명 → 노사협의회 등 30인 이상 규정 포함 전 항목 적용"*)은 추출값을 기준으로 자동 생성됩니다.
인식되지 않은 항목은 `—`로 남고, 상단 로그에 미인식 목록이 표시되어 직접 채워 넣을 수 있습니다.

## 문서 구성 (19페이지)

| 페이지 | 내용 |
|---|---|
| 1 | 표지 |
| 2 | 목차 (CONTENTS) |
| 3~4 | **01 회사 개요 및 현황** — 기업개요 · 신용/등기 상태 · 주주 · 경영진 · 거래처 · 사업장 · 업계순위 |
| 5~7 | **02 재무제표 현황** — 손익계산서 · 재무상태표 · 주요 재무비율(업종평균 비교) |
| 8 | **03 기업인증 및 산업재산권 현황** |
| 9~10 | **04 회사 점검항목 총괄** — 6개 영역 점검 프레임 · 2026년 세법개정안 영향 |
| 11~17 | **05 영역별 점검항목 상세** — ① 세무 ② 노무(비치·게시 / 지급·이행) ③ 정관 ④ 법무·등기 ⑤ 보험 ⑥ 인증·지식재산 |
| 18 | **06 실행 우선순위 및 컨설팅 로드맵** |
| 19 | 마무리 |

9~17페이지의 법정 점검항목(노무 의무사항, 정관 표준 프레임, 세법개정안)은 회사와 무관한 표준 내용이라 양식이 그대로 유지되고, 회사별 수치(근로자 수, 이자비용, 퇴직급여·보험료 추이, 인증 보유 현황 등)만 추출값으로 치환됩니다.

## 데이터 처리 방식

업로드한 파일은 **브라우저 안에서만 처리**되며 어떤 서버로도 전송되지 않습니다.
파일 파싱, 양식 작성, PPTX 생성이 모두 클라이언트 측 JavaScript로 수행됩니다.
(외부 통신은 CDN에서 라이브러리를 내려받는 것뿐입니다.)

기업신용조사보고서·재무자료는 대외비인 경우가 많으므로, 이 저장소에 **실제 회사 자료를 커밋하지 마세요.**
`.gitignore`에 `*.pdf` `*.xls` `*.xlsx` `*.pptx` 등이 기본으로 포함되어 있습니다.

## 기술 스택

| 라이브러리 | 용도 |
|---|---|
| [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) 3.12 | 편집 가능한 PPTX 생성 (표 · 도형 · 네이티브 차트) |
| [PDF.js](https://mozilla.github.io/pdf.js/) 3.11 | PDF 텍스트 추출 (좌표 기반 행·공백 재구성) |
| [SheetJS](https://sheetjs.com/) 0.18 | XLSX / XLS / CSV 파싱 |
| [JSZip](https://stuk.github.io/jszip/) 3.10 | DOCX / PPTX 내부 XML 텍스트 추출 |

프레임워크 없이 순수 JavaScript로 작성되었습니다.

## 코드 구조

`index.html` 하나에 다음 순서로 들어 있습니다.

| 파트 | 역할 | 수정 포인트 |
|---|---|---|
| PART A | 공통 유틸 (숫자 포맷, 증감률, 경로 접근) | |
| PART B | 파일 → 텍스트 추출 (`fileToText`, `pdfToText` 등) | 새 파일 형식 추가 |
| PART C | 텍스트 → 데이터 추출 (`extractData`) | **다른 보고서 양식 대응 시 여기 수정** |
| PART D | 데이터 → 문서 모델 (`buildDoc`) | 표 구성 · 점검항목 문장 · 기본 문구 변경 |
| PART E | 슬라이드 레이아웃 정의 (`S1`~`S19`, 인치 단위) | **페이지 추가·삭제·배치 변경** |
| PART F | 미리보기 렌더링 · 목차 네비게이션 | |
| PART G | PPTX 내보내기 (`addElPptx`, `exportPptx`) | |
| PART H | 업로드 처리 · 이벤트 · 초기화 | |

**PART E의 좌표는 인치 단위**이며 미리보기(1인치 = 96px)와 PPTX가 같은 값을 사용합니다.
따라서 레이아웃을 한 번만 고치면 화면과 다운로드 결과가 함께 바뀝니다.

발표자·연락처·문서 제목 같은 고정 문구는 PART D의 `D.meta`에 있습니다.

```js
meta:{
  title: '기업 컨설팅 브리핑',
  presenter: '○○센터 법인사업부 법인팀장 ○○○ | 연락처:000-0000-0000',
  confid: 'CONFIDENTIAL  |  경영 컨설팅 자료 · 대외비',
  ...
}
```
