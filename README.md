# 기업 컨설팅 브리핑 스튜디오

기업정보 리포트를 올리면 **회사 개요 · 재무제표 · 인증/산업재산권**을 시각화하고,
그 내용을 근거로 **세무 · 노무 · 법무 · 보험 · 인증** 브리핑을 만든 뒤
**수정 가능한 PPTX**로 내려받는 단일 파일 웹 도구입니다.

## 실행

`index.html` 을 브라우저에서 열면 됩니다. 설치·서버 불필요.
(분석·차트·PPT 생성 라이브러리를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 화면 구성

- **좌측 목차** — 섹션별로 묶인 전체 페이지 목록, 페이지 번호와 우선순위 색점
- **가운데 캔버스** — 실제 PPT 슬라이드와 동일한 16:9 페이지가 세로로 나열, 줌(축소·확대·100%·너비맞춤)
- **상단 바** — 데이터 검증 · 파일 업로드 · 초기화 · 테마 · 인쇄 · PPTX 다운로드

슬라이드의 텍스트는 **더블클릭하면 그 자리에서 수정**할 수 있습니다.

### 목차 너비 조절

목차 오른쪽 경계를 **좌우로 끌면 너비가 바뀌고, 글자 크기도 같이 따라갑니다**
(150px / 10.5pt ~ 480px / 15.5pt). 좁히면 쪽번호가 자동으로 숨어 제목 자리를 넓혀 줍니다.

- **끌기** — 경계선을 잡고 좌우로
- **두 번 클릭** — 기본값(246px)으로 복원
- **키보드** — 경계선에 포커스를 두고 ← → (Shift 누르면 크게), Home 으로 복원

바꾼 너비는 브라우저에 저장돼 다음에 열 때도 그대로이고, 너비를 바꾸면 슬라이드 확대율이
「너비맞춤」 상태일 때 자동으로 다시 맞춰집니다. 창이 좁을 때(900px 이하)는 목차가
겹침 방식으로 열리므로 조절 손잡이는 표시되지 않습니다.

## 화면 = PPT 동일 원본

화면 페이지와 PPT 슬라이드는 **하나의 페이지 정의(`buildPages`)** 에서 생성됩니다.
좌표는 인치 단위(슬라이드 10 × 5.625in)로 계산되고, 화면은 1in = 100px 로 그립니다.
따라서 화면에서 본 배치가 그대로 PPT가 되며, 페이지 수와 슬라이드 수가 항상 일치합니다.

## 지원 업로드 형식

| 형식 | 인식 방식 |
|---|---|
| `.xls` `.xlsx` `.xlsm` | 스프레드시트 시트 분석 — **인식률이 가장 높아 권장** |
| `.pdf` | 텍스트 좌표를 열로 복원해 표 재구성 |
| `.docx` | 표 + 본문 추출 |
| `.csv` `.tsv` `.txt` | 구분자 텍스트 (UTF-8 / EUC-KR 자동 판별) |
| `.html` `.htm` | HTML 표 추출 |

## 수치 색상 규칙

| 색 | 의미 |
|---|---|
| 초록 | 개선 · 업종 대비 우위 (이익 증가, 비용·부채 감소) |
| 빨강 | 악화 · 업종 대비 열위 (이익 감소, 비용·부채 증가) |
| 짙은 청록 | 핵심 수치 (최대주주 지분, 지분 평가액, 평균 이상 지표) |
| 회색 | 전기 동일 또는 판단 보류 |

## 재무제표 부호 표기

손익계산서 · 재무상태표에는 계정마다 부호 열이 붙습니다.

| 부호 | 뜻 |
|---|---|
| `+` | 가산 항목 |
| `−` | 차감 항목 — **금액도 음수로 표기**합니다 |
| `=` | 소계 · 합계 |
| `·` | 상위 계정의 세부 항목 (합산 대상 아님) |

차감 계정을 음수로 적기 때문에 열을 위에서 아래로 그대로 더하면 소계가 나옵니다.
예를 들어 매출액 `10,346,628` + 매출원가 `-8,976,126` = 매출총이익 `1,370,502` 입니다.
자본 구성이 합계와 맞지 않으면(자본조정·자본잉여금 등) 해당 계정을 찾아 표시하고,
그래도 남으면 「기타 자본항목」 행으로 드러내 항상 합계가 맞게 합니다.

**색상** — 증감과 부호는 `+` **파랑**, `−` **빨강** 입니다.

- 증감 열은 전기 대비 `+4.3%` · `-10.6%` 형태로 적습니다
- 가산(`+`) 계정은 파랑, 차감(`−`) 계정은 빨강, 소계(`=`)는 짙은 청록
- 부호 역할과 무관하게 **금액 자체가 음수면 빨강** (예: 자본조정 `-165,078`)
- 색은 **증감 방향**일 뿐 좋고 나쁨의 판정이 아닙니다. 업종 대비 우열은
  재무비율 표의 «우위 / 열위» 열이 따로 표시합니다

## 차트 규칙

색은 **역할별로** 나눠 씁니다. 같은 대상은 어느 차트에서나 같은 색을 갖고, 순위에 따라 색이
바뀌지 않습니다. 범주형 색은 CVD(색각이상) 분리도 검증을 통과한 고정 순서로만 배정합니다.

| 차트 | 형태 | 색의 역할 |
|---|---|---|
| 손익 3개년 추이 | 지표별 **작은 배수** (매출·영업이익·순이익 각각 자기 축) | 지표 구분 (범주형 3색) |
| 재무구조 | 누적 막대 | 유동부채 · 비유동부채 · 자본금 · 이익잉여금 4구간 구분 |
| 판관비 상위 | 가로 막대 | 금액 크기 = 한 색조의 진하기 |
| 업종평균 대비 | 대비 막대 | 우위(초록) · 열위(빨강) · 업종평균(회색) |
| 지분 구성 | 도넛 | 주주별 고유 색 + 이름·비율 직접 표기, 가운데 합계 |
| 거래처 비중 | 가로 막대 | 거래처별 고유 색, 특수관계는 ★ + 점선 테두리 |

축은 언제나 하나만 둡니다(척도가 다른 지표는 작은 배수로 분리). 구간 사이에는 2px 간격을
두고, 값은 필요한 곳에만 직접 표기하며, 글자는 색이 아닌 잉크 색을 씁니다. 2계열 이상이면
범례가 항상 붙어 색만으로 구분하지 않아도 읽힙니다. PPT 차트도 **화면과 같은 색·같은 구성**
으로 생성됩니다(네이티브 차트라 파워포인트에서 데이터 편집 가능).

## 기업신용등급

KODATA 리포트는 기업신용등급을 **게이지 이미지로만** 싣습니다. `.xls` · `.pdf` 어디에도
등급 문자열(`bbb-` 등)이 텍스트로 들어 있지 않습니다.
(리포트에 보이는 «EW 등급»은 값이 아니라 옆에 있는 다른 카드의 제목입니다.)

그래서 **원본 파일에서 게이지 그림을 그대로 꺼내** 화면과 PPT에 싣습니다.

| 형식 | 추출 방법 |
|---|---|
| `.xls` | Workbook 스트림의 `MsoDrawingGroup` + `CONTINUE` 레코드를 이어 붙여 PNG 복원 |
| `.xlsx` `.xlsm` | zip 안 `xl/media/*` |
| `.pdf` | 페이지의 이미지 XObject 를 캔버스로 옮김 |

여러 그림 중 신용등급 게이지는 **가로세로비 약 2:1 + 채도 있는 색조가 한 갈래**(금색 호)인 것으로
가려냅니다. 같은 크기의 기업성장등급 게이지는 무지개색이라 색조가 여러 갈래로 잡혀 걸러집니다.
보유 리포트 38개 전부에서 동일하게 동작합니다.

브리핑 **문구에 등급을 인용**하려면(예: 메인비즈 항목의 «기업신용등급 bbb-») 「파일 업로드 ·
요청사항」 패널의 **기업신용등급** 칸에 값을 적어 주세요. 이때는 `aaa` ~ `d` 스물두 단계를
인식해 자체 게이지로도 그립니다.

| 구간 | 등급 | 색 |
|---|---|---|
| 우량 | aaa ~ a- | 초록 |
| 보통 | bbb+ ~ bbb- | 금색 |
| 주의 | bb+ ~ b- | 주황 |
| 취약 | ccc+ ~ d | 빨강 |

평가일자와 결산일자는 원본에서 자동으로 읽어 게이지 아래에 표시합니다.
그림도 못 찾고 입력도 없으면 «미확인»으로 두고 검증 리포트에 표시합니다 —
값을 임의로 채우지 않습니다. 현금흐름등급(CR3 등)은 원본에 텍스트로 있어 자동 인식됩니다.

## 전체 코드 다운로드

상단 «코드 다운로드» 버튼을 누르면 이 도구 전체가 **HTML 한 파일**(`기업컨설팅브리핑_스튜디오.html`)
로 저장됩니다. 화면에 그려 둔 페이지는 비우고 원본 구조만 담기므로, 받은 파일을 브라우저로
열면 그대로 다시 동작합니다. 사내 배포나 백업에 쓰시면 됩니다.

## 업로드 반영 검증

업로드할 때마다 **검증 리포트**가 자동으로 갱신됩니다(상단 «데이터 검증»).

- 기업명 · 대표자 · 등급 등 주요 값이 실제 페이지에 실렸는지 대조
- 회계 항등식 점검 — 자산 = 부채 + 자본, 매출 − 원가 = 매출총이익, 판관비 항목 합 = 판관비
- 주주 · 거래처 · 사업장 · 동종업계 · 인증표 인식 여부

인식하지 못한 항목은 **비워 두고 «미인식»으로 표시**합니다. 다른 기업 데이터를 섞거나
0으로 채우지 않습니다. 거래처의 상호·대표자가 주주·임원·관계회사와 일치하면
**특수관계 거래처로 자동 표시(★)** 됩니다.

## 페이지 역할 분담 (중복 없음)

같은 내용이 여러 장에 반복되지 않도록 각 페이지가 맡는 역할을 나눴습니다.

| 페이지 | 맡는 것 | 맡지 않는 것 |
|---|---|---|
| 목차 | 섹션과 페이지 범위 | 상세 페이지 제목 (8쪽 넘는 묶음은 범위만) |
| 04 점검 프레임 | 우선순위 × 영역 교차표, 영역별 점검 관점 | 개별 항목 나열 |
| 04 영역별 점검표 | 항목 목록 · 우선순위 · 기대효과 · **상세 쪽번호** | 근거법령 · 실행방안 |
| 05 항목별 상세 | 현황 · 산출근거 · 근거법령 · 실행방안 · 기대효과 | — |
| 06 실행 로드맵 | 시기별 실행 순서 + 상세 쪽번호 | 근거·실행 내용 |
| 06 인용 법령 목록 | 법률 단위 목록과 관련 영역 | 조문 (상세 페이지에 있음) |

「항목별 상세 페이지 포함」을 끄면 점검표가 근거법령·실행방안까지 싣는 형태로 자동 전환됩니다.

## 구성 페이지

표지 · 목차 / 01 회사 개요(개요·신용상태, 주주·경영진·관계회사, 거래처·사업장, 연혁·사업목적) /
02 재무제표(손익, 재무상태, 현금흐름·원가, 재무비율·진단, 동종업계 비교) /
03 인증·산업재산권 / 04 영역별 점검표 / 05 항목별 상세(현황·산출근거·근거법령·실행방안·기대효과) /
06 실행 로드맵 · 인용 법령 색인 · 데이터 출처와 유의사항

브리핑 항목은 고정 문구가 아니라 **업로드된 수치에서 조건이 성립할 때 생성**됩니다.
가지급금이 0이면 해당 항목이 나타나지 않고, 매출 규모에 따라 소기업/중기업 판정과
중소기업 특별세액감면율(10% / 5%)이 자동으로 달라집니다.

「파일 업로드 · 요청사항」 패널에서 표지 정보, 기업 기본정보, 섹션별 요청사항,
페이지 구성 범위(항목별 상세 포함 여부)를 지정할 수 있고, 입력값은 브라우저에 자동 저장됩니다.

## 유의

법령 내용은 작성 시점 기준이며, 특히 조세특례제한법상 감면·공제는 적용기한이 매년 개정됩니다.
산출근거의 금액은 공개 재무데이터에 기초한 추정치이므로, 실제 집행 전 세무대리인·공인노무사·
변호사 등 각 분야 전문가의 검토가 필요합니다.
